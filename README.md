## 概要
React / TypeScript / React Three Fiber を用いて作成した3Dコンテンツ表示アプリです。

## 使用技術
- React
- TypeScript
- React Three Fiber

## 主な機能
- 3Dコンテンツの表示
- コメント投稿機能
- 文字色変更機能

## 工夫した点
コンポーネントの責務を分離し、再利用性を意識した設計を行いました。  
また、不要な再レンダリングを防ぐため、メモ化を意識した実装を行っています。

- API連携によるデータ永続化
- UI/UXの改善
- パフォーマンス最適化
